# 国内云服务器部署说明

按顺序执行即可。整体时间线：买服务器 10 分钟 → 部署上线 30 分钟 → 备案 1~3 周（期间用 IP:端口访问）→ 备案通过后绑域名 + HTTPS。

## 0. 购买与备案前置（这是唯一耗时的部分，建议先做）

- 服务器：阿里云 / 腾讯云「轻量应用服务器」，**1核2G / Ubuntu 24.04 LTS（推荐，Python 3.12）** 即可，约 30~60 元/月（学生认证有更低价格）。
- 域名：买一个（.com/.cn 均可，几十元/年），**必须完成实名认证**（备案前提）。
- 备案：登录云厂商备案系统，用服务器的「备案服务号」提交个人备案（身份证 + 手机号 + 人脸核验）。云厂商初审 1~2 天，提交管局后约 **7~20 个工作日**。
- 备案没通过之前：服务器会封 **80/443 端口**，但其他端口（如 8000）可用，所以下面第 1~7 步可以先全部做完、用 `http://服务器IP:8000` 正常访问测试，不耽误时间。

## 1. 服务器初始化

```bash
sudo apt update && sudo apt install -y python3 python3-pip git nginx
```

Ubuntu 22.04+ 自带 Python 3.10+，满足要求（本项目需 3.10+，因为代码用了 `int | None` 类型写法）。

## 2. 上传代码

把本机的 `backend/`、`frontend/`、`run.py`、`requirements.txt` 传到服务器的 `/opt/f1-site/`（两种方式任选）：

```bash
# 方式 A：本机 Git Bash 里 scp（把 1.2.3.4 换成你的服务器 IP）
scp -r backend frontend run.py requirements.txt deploy root@1.2.3.4:/opt/f1-site/

# 方式 B：先把项目推到 GitHub，服务器上 git clone
```

## 3. 安装依赖

```bash
cd /opt/f1-site
sudo pip3 install -r requirements.txt --break-system-packages
```

## 4. 上传凭据（可选，但强烈建议）

在 `/opt/f1-site/data/` 目录放两个文件（目录首次运行会自动创建，也可以手动 `mkdir -p /opt/f1-site/data`）：

- `bili_cookie.txt`：你浏览器登录 B站 后复制来的 Cookie。没有它，服务器（数据中心 IP）抓 B站 很容易被风控，抓取大概率失败。本机已有的这个文件直接 scp 上去即可。
- `deepseek_key.txt`：DeepSeek API Key。没有它帖子只显示原文、没有 AI 摘要。

## 5. 放行端口

在云控制台「防火墙 / 安全组」放行 TCP **8000**（后续用 nginx 后可以只留 80/443）。

## 6. 先手动跑一次验证

```bash
cd /opt/f1-site
sudo F1_HOST=0.0.0.0 python3 run.py
```

浏览器打开 `http://服务器IP:8000`，能看到积分榜、能手动抓取一次，即成功。Ctrl+C 停掉。

## 7. systemd 常驻（开机自启 + 崩溃自动重启）

```bash
sudo cp /opt/f1-site/deploy/f1-site.service /etc/systemd/system/
sudo useradd -r www-data 2>/dev/null || true        # 若系统没有 www-data 用户
sudo chown -R www-data:www-data /opt/f1-site        # 让服务用户能写 data/f1.db
sudo systemctl daemon-reload
sudo systemctl enable --now f1-site
sudo systemctl status f1-site                        # 看到 active (running) 即成功
```

编辑 `/etc/systemd/system/f1-site.service`，**取消注释并修改** `SCRAPE_TOKEN=...` 为你自己的随机口令（建议设，否则任何人访问你的网站都能点「手动抓取」消耗你的抓取额度）。改完执行 `sudo systemctl daemon-reload && sudo systemctl restart f1-site`。

服务日志：`sudo journalctl -u f1-site -f`

## 8. 备案通过后：域名 + Nginx + HTTPS

```bash
# 域名解析：在域名控制台加一条 A 记录指向服务器 IP
sudo cp /opt/f1-site/deploy/nginx.conf /etc/nginx/sites-available/f1-site
sudo vi /etc/nginx/sites-available/f1-site   # 把 f1.example.com 换成你的域名
sudo ln -s /etc/nginx/sites-available/f1-site /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
# 申请免费 HTTPS 证书（Let's Encrypt）
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d 你的域名
```

之后访问 `https://你的域名` 即可，Nginx 会自动把流量转发给 8000 端口的应用。

## 9. 日常更新

```bash
cd /opt/f1-site
sudo git pull          # 或重新 scp 覆盖改动的文件
sudo systemctl restart f1-site
```

## 注意事项

- **数据备份**：所有帖子存在 `/opt/f1-site/data/f1.db` 单个文件里，偶尔 `scp` 到本机即可。
- **B站 Cookie 有效期**：一般几周失效，抓取开始报错（-412 / 风控）时更新 `data/bili_cookie.txt` 并 `systemctl restart f1-site`。
- **DeepSeek 费用**：每篇摘要几厘钱量级，个人用几乎可忽略。
- **Jolpica（F1 数据源）** 是国外服务（Cloudflare），国内服务器一般可直连，偶尔慢；若不稳定可在代码里加代理。
- 国内服务器抓 B站 天然有优势（同网络环境），抓小红书以后再议（反爬最严，风险自理）。
